# 更新日志 · M1「保底播放器」

发布：`v0.1.0-m1`（2026-09-05） · 对应 [ROADMAP](ROADMAP.md) M1 · 上一个版本：无（首发）

## 新装用户 30 秒上手

1. [Release 页](https://github.com/MOLIEER66/raoliang/releases) 下载 `app-release.apk`，手机点击安装（系统提示「未知来源」时允许）
2. 首次打开 → 点「扫描本地音乐」→ 授权读取音频文件
3. 点任意一首歌 → 出声

## 本次更新带来了什么

核心：本地音乐的完整播放链路——扫描 → 音乐库 → 播放 → 后台。

| 能力 | 说明 |
| --- | --- |
| 本地音乐扫描 | 读取手机里已有的 MP3/FLAC 等音频，增量同步，不重复扫 |
| 音乐库三标签 | 全部 / 最近播放 / 最常播放 |
| 正在播放页 | 沉浸式大封面、可拖动的声纹进度条、随机/顺序/单曲循环三种播放模式 |
| 后台播放 | 通知栏 + 锁屏媒体控制；Home 键退出不停歌；拔耳机/断蓝牙自动暂停 |
| Echo Palette 动态取色 | 播放页配色随封面实时变化，每首歌一套专属氛围 |
| 深色模式 | 跟随系统 |
| 预测性返回 | Android 16 新手势适配：返回时实时预览上个页面 |

## 已知限制（后续版本安排）

- 暂无歌词逐行滚动（M2）
- 暂无在线音源（M2：洛雪自定义音源脚本导入）
- 搜索/歌单/设置为占位空态（M3）
