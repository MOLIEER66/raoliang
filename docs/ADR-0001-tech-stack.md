# ADR-0001 · 技术栈选型：Kotlin + Jetpack Compose + Media3

状态：✅ 已接受（2026-09-05）

（ADR = 架构决策记录：每个关键选择写一篇"当时为什么这么选"，面试时直接引用，防止被追问问穿）

## 背景

开发者完全零基础、AI 辅助开发；目标设备为 Android 16 真机；项目核心目标是校招面试作品；不着急，质量优先。

## 决策

采用 **Kotlin + Jetpack Compose + Media3**（Android 官方原生技术栈）。

## 为什么是它

1. "适配安卓 16"的全部谈资（前台服务合规、预测性返回、Edge-to-edge）都是原生系统特性——用官方栈讲官方故事，叙事天然一致
2. 校招 Android 客户端岗位匹配度最高
3. 对零基础者的真实含义：你不需要会写，但需要**读懂并能讲清**。学习路径随 M1-M2 同步进行

## 为什么不是别的

| 候选 | 结论 | 理由 |
| --- | --- | --- |
| Flutter | 备用，否 | 出效果更快，但"安卓 16 适配"会被引擎层隔一层，面试深度打折。若 M0 环境严重受阻可重新评估 |
| React Native | 否决 | 叙事匹配前端岗，与目标不符 |
| WebView 套壳 | 否决 | 一眼假，面试自杀 |
| 同时做 iOS | 否决 | 工作量翻倍，烂尾概率暴涨 |

## 后果

- 开发机需安装 Android Studio（M0 有"环境体检"步骤，照着点即可）
- 日常循环：改代码 → push → CI 自动出 APK → 手机安装 → 验收
