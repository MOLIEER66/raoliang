# ADR-0002 · 音源插件系统：兼容洛雪协议

状态：✅ 方向已接受（2026-09-05），细节随 M2 细化

## 决策

应用本体 = 播放器 + 插件宿主。所有在线能力（播放地址 / 歌词 / 封面）由**用户自备**的洛雪（LX）格式脚本提供；本仓库不内置任何脚本、任何服务器地址。

## 理由

1. **法律与平台安全**：与洛雪官方同一立场——播放器中立，内容用户自备
2. **生态复用**：现成大量洛雪音源脚本可直接使用，不需要自己维护后端；HYWmusic 公益版脚本即首个测试用例
3. **面试叙事**："我设计了一个受限脚本沙箱和插件协议" 远好于 "我接了一个免费接口"

## 技术要点（M2 细化）

- 脚本运行环境：受限 JS 引擎（具体方案随技术栈在 M2 定），只暴露白名单 API（网络请求、事件回调）
- 协议面：musicUrl / lyric / pic；搜索不走脚本，走服务端聚合接口（PRD §5）
- 失效处理：多源冗余、单源失败自动降级、错误提示可读
- 安全边界：脚本无文件系统 / 通讯录等敏感权限；网络请求域名可审计展示给用户
