# ADR-0005 · 品牌命名：绕梁（Raoliang）

状态：✅ 已接受（2026-09-05）

## 背景

原名「回声音乐 EchoMusic」撞名实证（检索日期 2026-09-05，完整检索过程见 DESIGN-SYSTEM §8.3）：

- GitHub 已有同名项目 `hoowhoami/EchoMusic`
- Google Play 已有多款「Echo Music」产品
- App Store 已有《余响 EchoSpace》私有云音乐播放器（连 Echo 前缀都撞）
- 候选「余响」「余音」也分别撞名，已排除并记录

## 候选对比（三者均经检索排除重大撞名）

| 候选 | 出处与含义 | 检索结论 |
| --- | --- | --- |
| **绕梁** | 余音绕梁，三日不绝——《列子·汤问》 | 未发现同名音乐 App / 播放器 |
| 三叠 | 《阳关三叠》——一唱三叹、旋律回环 | 无同名播放器，检索指向古琴曲 |
| 空谷 | 空谷传声——《千字文》 | 无同名音乐 App，仅一家同名建站公司 |

## 决策

定名 **「绕梁」**（拉丁化写法 Raoliang）。理由：

1. 字面即"声音停了还在响"——是封面取色"回声"概念的汉语原生表达，与声纹波形视觉语言同构
2. 典故出自《列子·汤问》，面试 30 秒讲清来龙去脉
3. 三者中检索歧义最小、气质最贴合深色沉浸的调性

## 边界与不可变项

- `applicationId` 保持 `com.echomusic.app` 不变：改包名会破坏已装用户的升级路径；品牌名 ≠ 包名（此取舍本身可作面试谈资）
- GitHub 仓库更名 `MOLIEER66/echomusic` → `MOLIEER66/raoliang`（旧地址自动重定向）
- 主题资源类名 `Theme.Raoliang`、CI 产物名 `Raoliang-*-apk` 随更名同步更新
