# 回声音乐 EchoMusic · 设计系统 v1.0

> 配套文件：[SCREENS.md](SCREENS.md)（逐屏规格）· [mockups.html](mockups.html)（高保真视觉稿，1px = 1dp）
> 实现基线：Kotlin + Jetpack Compose + Material 3 · Android 10+（Android 16 优先）· **深色优先** · Edge-to-edge 全程沉浸

## 0. 一句话定位

给 QQ 群里的年轻人用的本地播放器：本体零曲库、靠用户自备的洛雪音源起飞。气质是「深夜、耳机、自己的歌」，不是「信息流、推荐、社交广场」。视觉上的一切决定都为两件事服务：**听歌时够沉浸，截图发群时有辨识度。**

## 1. 设计理念 · 签名概念：「界面是封面的回声」（Echo Palette）

每一首歌开始播放时，系统从专辑封面提取种子色，生成一整套 tonal 配色——背景、主色、光晕、进度条、播放键全部随之变化。音乐库和搜索在未播放时是安静的「回声黑 × 回声青」，而一旦播放，整个 App 变成这首歌的房间：听《夜曲》是靛蓝夜色配香槟金的月晕，切到《晴天》又变成奶油晨光配天青色。动态取色只发生在**氛围层**（背景、光晕、主控件），正文永远走中性灰阶，语义色永不漂移——沉浸而不失读性。

**记忆点一句话：别人换皮肤是用户选颜色，EchoMusic 的颜色是歌曲给的。**

### 1.1 取色流水线（封面 → 界面）

1. **解码**：读取内嵌封面（ID3/APIC 或音源接口返回），下采样到 128×128，转 CIELab。
2. **聚类**：K-means（k=6，≤10 轮）得到主色簇；过滤 L* < 12 与 L* > 92（纯黑纯白不作种子）。
3. **打分**：`S = 0.5·彩度 + 0.3·覆盖率 + 0.2·亮度带权重`（L* 40–70 加权最高，避开焦黑与过曝）。
4. **选定**：最高分为 **seed（种子色）**；次高且色相差 > 30° 的簇为 **glow Hue（光晕辅助色相）**。
5. **展开**：seed 走 HCT（material-color-utilities）生成 tonal 色阶，按下表映射到语义令牌。
6. **护栏**：见 1.3；任何一步失败都回退品牌基准色板（§2.1）。

### 1.2 浅色 / 深色映射策略

| 令牌 | 深色（优先） | 浅色 |
| --- | --- | --- |
| background（画布） | `HCT(seed.h, min(C,10), T=8)` —— 极深且带封面色相 | `HCT(seed.h, min(C,8), T=97)` —— 极浅微染 |
| surface / surfaceContainer | T=12 / T=16（同色相低彩） | T=99 / T=94 |
| primary | `HCT(seed.h, clamp(C,45,88), T=80)` | `HCT(seed.h, clamp(C,40,72), T=38)` |
| onPrimary | T=12（同色相） | T=100 |
| onSurface | T=94（彩度 ≤ 4 的中性） | T=13 |
| onSurfaceVariant | T=66 | T=42 |
| glow 光晕（沉浸背景 radial） | `HCT(glowHue, C·0.8, T=28)`，30–35% alpha | 同左，35–50% alpha |
| 封面投影 | 光晕色加深至 40–55% alpha | 光晕色 20–25% alpha |

规则：**深色把封面色相「藏进黑里」，浅色把封面色相「洗在白上」**；同一首歌两种模式色相一致、明度相反。沉浸屏（正在播放/歌词/歌单头图）永远比列表屏更深一档（深色）/更暖一档（浅色）。

### 1.3 护栏（永远成立的三条）

1. **正文永不变色**：onSurface / onSurfaceVariant 只由中性灰阶（彩度 ≤ 4）构成，任何封面下都可读。
2. **对比度硬门槛**：正文 ≥ 4.5:1、大字号与图形 ≥ 3:1；映射后不满足则沿 tone 轴 ±6 步进调整直至满足。
3. **失败必有兜底**：灰度封面（C < 8）→ 回退品牌回声青基准板；无封面文件 → 按「歌手+曲名」hash 从 8 组内置「回声渐变」中确定性地选一组（同一首歌永远同一配色，不是随机彩虹）。语义色（error 等）与音源徽章点色（§2.3）不参与动态映射。

### 2.2 动态取色映射（播放态）

播放中的页面（含迷你条与导航）整体切换到由 seed 生成的 ColorScheme，映射规则见 §1.2。实现上即「运行时构建 darkColorScheme/lightColorScheme」。列表屏在播放时也跟随变色（呼吸感），但正文对比护栏不变。

### 2.3 语义色与固定功能色（不随封面变）

| 令牌 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |

| success | `#6FE0A8` | `#1B7F4D` | 扫描完成、源正常 |
| warning | `#FFC46B` | `#9A6A00` | 限速提示（HTTP 429） |

音源徽章圆点色（固定，口径全 App 一致）：洛雪·公益版 `#4FE3C1` · 洛雪·自建 `#9D8CFF` · 本地 `#8A939B` · 失效 `#FF8A80`。

### 2.4 渐变与光晕

- 沉浸背景 = `radial 光晕×2 + linear 基底`：光晕 1 在左上（主色系，30–50% alpha），光晕 2 在右下（glow Hue），基底为 background 的同色相深/浅 tonal。禁止彩色噪点、禁止大面积纯黑纯白。
- 进度条与播放键允许**同色系明度渐变**（primary ±8% 明度）；禁止跨色相彩虹渐变。
- 所有渐变在取色切换时以 600ms crossfade 过渡（见 §6.3）。

## 3. 字体排印

### 3.1 字族策略

**不内置任何字体**（APK 体积与版权双赢）：中文交给系统默认无衬线（MiSans / HarmonyOS Sans / OPPO Sans / PingFang 顺势接管），Latin 与数字同源。所有时间、计数、时长启用 **tabular-nums（等宽数字）**——这是「播放器感」最重要的隐形细节：数字跳动时不抖动。禁用斜体、禁用下划线链接（用主色表达可点击）。

## 4. 形状 · 间距 · 层次 · 图标

### 4.1 间距系统（4dp 栅格）

令牌：`s4 s8 s12 s16 s20 s24 s32 s40 s48 s64`。

- 页面水平边距 **20**；沉浸屏水平边距 **26**（大封面区 **28**）。
- 列表行内边距 20/12；卡片内边距 16；区块间距 24；分组间距 32。
- 规则：相邻层级留白至少差一档；同一行元素间距统一（列表内 gap 12）；禁止出现非 4 倍数的 magic number。

### 4.2 圆角体系

| Token | dp | 用途 |
| --- | --- | --- |
| r-xs | 6 | 进度端帽、小圆点 |
| r-sm | 10 | 44dp 列表封面、小缩略图 |
| r-md | 14 | 列表按压底、小组件 |
| r-lg | 18 | 迷你播放条、热词卡 |
| r-xl | 24 | 大封面（334dp）、设置分组卡 |
| r-2xl | 28 | 底部弹层顶角 |
| full | 999 | 按钮、输入框、chips、徽章 |

规则：圆角 ≈ 元素短边的 8%–12%；**封面必有圆角，全 App 无直角封面**；同一容器内圆角向内收缩（外 24 内 14）。

### 4.3 阴影与层次（深色优先的做法）

深色模式不靠投影，靠「色阶 + 发丝线 + 光晕」：

| 层 | 定义 | 处理 |
| --- | --- | --- |
| L0 画布 | background | 沉浸屏为封面 tonal 渐变 |
| L1 容器 | surface / surfaceContainer | +1dp 发丝线 outlineVariant |
| L2 浮层 | 迷你条、弹层、导航 | 浅色：`0 12 28 rgba(0,0,0,.12)`；深色：仅发丝线 + 顶部 1px 高光 `rgba(255,255,255,.05)` |
| L3 沉浸光晕 | 播放页背景 radial | 属背景，不参与层级判断 |

阴影档位：shadow-1 `(0,2,8,6%)` 仅浅色 · shadow-2 `(0,12,28,20%|深色40%)` · shadow-3 封面 `(0,32,64,40–55%)`（色相取自光晕）。触摸反馈：一切可点元素 8% onSurface stateLayer，圆形控件 12%。

### 4.4 图标风格

- 24dp 栅格、**2dp 描边、圆头圆角**（round cap / round join）；视觉重心统一 2dp 内缩。
- 填充态仅用于「选中 / 进行中」语义：播放、暂停、已收藏的心形、单曲循环。
- 尺寸：24 = 导航与顶栏 · 20 = 行内与按钮内 · 18 = 行尾辅助 · 34 = 上下曲 · 32 = 播放大键内部 · 17 = 药丸按钮内。
- 禁止描边与填充风格混用（语义填充除外）；禁止双色调图标。

- 高 **17**、圆角 full、水平 padding 7、1dp outline 描边、labelSmall(10/600)、前置 4dp 圆点（色见 §2.3）、无底色。
- 变体：`洛雪·公益版` / `洛雪·自建` / `本地 FLAC` / `失效`（描边与文字转 error 40%）。

### 5.8 空状态 / 加载 / 错误

- **空状态**：64dp 线性插画（同心圆弧「回声波纹」，onSurface 24%）+ titleMedium 标题 + bodyMedium 说明 + 次按钮。文案禁「暂无数据」，必须给原因和动作：例 → 「还没有歌曲」/「扫描手机里的本地音乐」/［扫描本地音乐］+ 幽灵［导入洛雪音源脚本］。
- **加载**：列表用 3–5 行骨架（64dp 灰块 + 1.2s 微光扫过）；播放页封面 shimmer；**禁止全屏 spinner**。
- **错误**：三件套 = 原因（titleMedium）+ 细节（bodyMedium，含可读错误码如 `HTTP 429`）+ 出路（主按钮「重试」+ 幽灵兜底入口「改用本地文件」/「导入洛雪脚本」）。轻量变体：内联横幅 40dp（error 12% 底 + error 文字 + 关闭），用于「音源失效，已自动切换」类非致命通知。

## 6. 动效规格

### 6.1 时长档位

`instant 80ms`（按压反馈）· `fast 150`（交叉淡入）· `base 250`（控件出入场）· `slow 400`（共享元素）· `expressive 600`（调色、大幅位移）· `theme 800`（Echo Palette 切换）。

### 6.2 缓动曲线

- **emphasized** `cubic-bezier(0.2, 0, 0, 1)` —— 进场、展开、共享转场默认。
- **standard** `cubic-bezier(0.4, 0, 0.2, 1)` —— 一般属性。
- **decelerate** `cubic-bezier(0, 0, 0, 1)` —— 手势释放。
- **spring** dampingRatio 0.85 / stiffness 380 —— 播放/暂停图标变形、导航声波。

### 6.3 关键转场

**a) 迷你条 ↔ 播放页（签名转场）**
封面共享元素：44→334、r10→r26、位置插值，400ms emphasized；背景向目标封面 palette 做 **800ms crossfade**（色相走最短路径）；迷你条与导航下沉 24dp + 淡出 250ms；播放页控件 stagger 入场（每项 +20ms，250ms emphasized，位移 12dp）。返回完全逆放，并支持**预测性返回跟手**（缩放 0.92 + 圆角 24→16 预览，Android 16 谈资点）。

**b) 切歌（停留播放页）**

## 7. 工程落地注记（Compose）

- 令牌以 Material 3 `ColorScheme` 承载；动态播放态在运行时由取色器构建 `darkColorScheme()/lightColorScheme()`，并扩展 `glow`、`coverShadow` 两个沉浸专用 token（CompositionLocal）。
- 取色：封面向下采样 128px → `material-color-utilities`（HCT）打分；K-means 跑在 `Dispatchers.Default`，结果缓存按专辑 ID。
- 状态栏图标明暗随 palette 亮度切换；Android 15+ 系统栏透明为默认，布局全部由 `WindowInsets` 驱动。
- 本文所有 dp/sp 为唯一口径；`mockups.html` 中 1px = 1dp。
