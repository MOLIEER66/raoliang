# 绕梁 Raoliang · 逐屏规格 v1.0

> 配套：[DESIGN-SYSTEM.md](DESIGN-SYSTEM.md)（令牌与组件口径）· [mockups.html](mockups.html)（静态视觉稿，1px = 1dp）
> v1.0 范围 6 屏：音乐库、正在播放、歌词、搜索、歌单详情、设置。

## 0. 通用约定

- **Edge-to-edge**：所有屏内容与背景延伸至状态栏与手势条之下，系统栏永久透明（Android 15+ 默认），布局由 `WindowInsets` 驱动。
- 安全区常量（视觉稿取值，实机以 WindowInsets 为准）：状态栏 inset ≈ **52**；手势条 inset = **26**（手势条本体 4.5dp 居中悬浮）。
- **沉浸屏**（正在播放/歌词/歌单详情头图）：背景直通四角，状态栏图标明暗随背景亮度切换；底部控件距底 = 26 + 12。
- **列表屏**（库/搜索/歌单/设置）：底部导航（82）磨砂延伸至手势区之下；列表底部内容内边距 = **176**（迷你条 62 + 间距 8 + 导航 82 + 缓冲 24）；迷你条隐藏时为 114。
- 错误三件套（原因 + 细节含错误码 + 出路/兜底）全局统一，见 DESIGN-SYSTEM §5.8。
- **品牌命名**：EchoMusic/回声音乐撞名（检索实证见 DESIGN-SYSTEM §8.3），App 内不露出 logo，对外物料品牌露出标注「（新名待定）」。
  - ✅ 定案：绕梁（Raoliang），候选对比与撞名检索详见 docs/ADR-0005-brand-naming.md
- 导航激活态 = 声波指示器（随播放律动）。

## 2. 正在播放（Now Playing · 沉浸 · 刊头式构图）

> 签名构图（DESIGN-SYSTEM §1.4 S2/S3）：**歌名竖排刊头 + 右置封面 + 歌词主体**的非对称双栏，与大封面垂直居中的主流构图（Apple Music 等）肉眼可辨地拉开。

### 布局（自上而下）

| 区域 | 规格 |
| --- | --- |
| 背景 | Echo Palette 沉浸渐变（radial 光晕×2 + linear 基底），直通四角；切歌时以「回声扩散」更新（§7） |
| 状态栏 | 图标明暗随背景亮度自动切换 |
| 顶栏 | top = inset + 14，高 24，水平 26：chevron-down 24 ／ 居中「正在播放」labelMedium 字距 3 onSurfaceVariant ／ 队列 24 |
| 刊头舞台 | margin `24/26/0`，高 264：**封面 264×264 r26 右置**（shadow-3 + 22% glossy 高光；外围双环余波 -14/-36dp、1.5dp 主色描边、透明度 .16/.07——回声扩散的静态暗示）；**左侧竖排刊头**（与封面同高）：歌名竖排 33/780/字距 7（仅 ≤6 字），下接 2×32dp 主色竖线（12dp 泛光），再接竖排副题 10.5/560/字距 1.5 |
| 歌词主体 | margin `34/26/0`：3.5dp 主色声标（14dp 泛光）+ 三行左对齐——上一行 14/500 sub、**当前行 22/740**、下一行 14/500 sub；点击/上滑进歌词页 |
| 操作行 | margin `18/26/0`：心形 24（已收藏=填充 primary，居左）｜右侧 gap 24：下载 22、更多 22 |
| 波形进度（S1） | margin `22/26/0`：48 根 4dp 圆角声纹柱（gap 3，高 3–18 随频谱包络），已播段 primary、未播段 outlineVariant；时间行 11sp tabular（左当前 `b/onSurface`、右剩余 onSurfaceVariant） |
| 控制行 | margin `24/26/0`：shuffle 23 ／ prev 34 ／ **播放 74 圆形 primary（图标 32 onPrimary，shadow=primary 35%）** ／ next 34 ／ repeat-one 23（循环单曲时角标 1） |
| 来源行 | margin `24/26/0`：音源徽章 + 11.5 onSurfaceVariant 说明（「经洛雪音源播放 · 无损 SQ」／「本地文件 · 44.1kHz/24bit」） |
| 手势条 | 系统层，背景延伸至其下；内容底 ≈ 742，与手势区保持 ≥90 呼吸 |

### 状态

- **正常（在线，经洛雪源）**：来源行徽章「洛雪·公益版」。
- **正常（本地）**：徽章「本地 FLAC」；说明为采样率/位深。
- **封面缺失**：按曲目 hash 使用内置回声渐变，刊头构图不变。
- **长歌名（>6 字）**：竖排转横排 27/720 单行省略，主色竖线与竖排副题保留。
- **加载/缓冲**：封面 shimmer；播放键换 20dp 环形进度；波形未播段出现缓冲脉动。
- **音源失效**：顶部内联横幅（40dp，error 12% 底）「洛雪·公益版 失效，已切换至 洛雪·自建」，3s 自动收起可手动关；播放不中断。
- **空态**：无播放时不进入此页（迷你条隐藏）。

### 安全区与转场

- 全屏沉浸：顶部控件避开状态栏（inset + 14），底部内容距手势条 ≥ 90。
- 进出：迷你条共享元素 morph 400ms + palette 800ms crossfade（DESIGN-SYSTEM §6.3a）；**预测性返回**跟手缩放。
- 切歌：**回声扩散**（DESIGN-SYSTEM §6.3b / S3）。
- 双击封面收藏；左右滑动封面切歌。

### 令牌

动态 palette 全套（§1.2 映射）+ glow / coverShadow 扩展 token + error（横幅）+ 徽章。

| 间奏行 | 3 × 5dp 圆点，40% |
| 底部控制 | 固定底部（距手势条 30）：细进度 3dp + 时间行；控制行：音源徽章｜prev 30 / 播放 54 圆形 primary / next 30｜队列 24 |
| 手势条 | 背景延伸 |

### 状态

- **正常**：如上。
- **无歌词**：居中「纯音乐，请欣赏」titleLarge + 封面 120dp r16 居中。
- **加载中**：4 行歌词骨架（透明度阶梯）。
- **未匹配**：「没有找到歌词」+ 幽灵按钮「搜索歌词」（联动搜索页预填歌名）。

### 交互与安全区

- 点击任意行 seek（行内涟漪 + 时间气泡）；拖动进度时列表 scale 0.96 冻结。
- 进入：播放页上滑或点预览行，垂直共享轴转场（封面淡出上移 300ms）；下滑返回。
- 安全区同播放页。

### 令牌

| 热门搜索 | 组头同上；2 列 grid gap 8，item 高 40 r12：名次 13/750 斜体（1–3 primary，余 onSurfaceVariant）+ 词 13/560 + 热度 10.5 onSurfaceVariant |

| 迷你条 + 导航 | 同全局，激活 = 搜索 |

### 状态

- **初始（未输入）**：只有最近 + 热门；框内占位「搜索歌名、歌手或专辑」。
- **输入中**：实时建议行（无封面，search 引导图标 + 文本高亮命中段 primary）。
- **加载**：3 行结果骨架。
- **正常**：如上（示例：`周杰伦` → 晴天 / 夜曲 / 七里香 / 稻香，徽章区分 洛雪·公益版 与 洛雪·自建）。
- **空结果**：「没有找到与《关键词》相关的歌曲」+ 幽灵「换个关键词试试」。
- **错误（服务端失效 / 429 限速）**：插画 48 + 「音源服务暂时不可用（HTTP 429）」+ 主按钮「重试」+ 幽灵「从本地音乐找」——PRD §5 兜底路径，永不把用户堵死。

### 安全区

- 搜索框吸顶于状态栏下；列表滚动时状态栏区域叠 24dp scrim 渐变保证图标可读。
- 结果行滚动手势区之上；导航磨砂延伸至底部。

### 令牌

surfaceContainer（框/chips/热词卡）· primary（光标、名次 1–3、命中高亮）· 徽章全套 · outline。

## 7. 屏间转场速查
